## src/pages 技术债/陈旧要素盘点（建议，不做修改）

- **HomePage.tsx**
  - 组件体量过大，集成登录、应用列表、背景切换、调试入口等多职责，缺少拆分与状态集中管理。
  - 大量内联样式和硬编码文案/路由，复用性差且难以统一主题。
  - API 应用和静态应用的跳转逻辑直接操作 `window.location`，缺少失败兜底与可测试性。
  - 调试应用、Toast、背景切换等调试逻辑混入正式功能，易引入意外状态。

- **DashboardPage.tsx**
  - 背景与字体样式硬编码在组件内，缺少全局主题/布局复用。
  - 未登录时仅返回静态卡片，没有统一的鉴权路由保护与重定向策略。

- **LoginPage.tsx**
  - 背景样式内联，返回主页按钮与 RegisterPage 重复实现，可抽取复用组件。
  - `loginMutation` 的错误类型为 `any`，缺少类型约束与统一错误提示。
  - “默认管理员账号”提示文本为废弃彩蛋，可能误导用户。

- **RegisterPage.tsx**
  - 与 LoginPage 共享的大量 UI/背景/按钮代码未抽象成组件。
  - 成功/失败提示及加载状态分散在本地 state，缺少统一的 form 状态管理或通知体系。
  - 可选字段 pushdeer_token 仍在验证 schema 中声明，缺少显式的后台能力校验。

- **AppsPage.tsx**
  - 组件同时承担应用展示、NKey 生成、用户资料更新等多职责，状态复杂且未模块化。
  - `pingUrl` 采用前端 HEAD 请求 + 5s 超时，未做中断/清理，在弱网下可能悬挂。
  - 多处使用 `alert`/`window.location.href` 进行错误提示和跳转，不利于可测试性与无障碍。
  - 背景、栅格样式硬编码且与主页样式重复，缺少复用层。

- **AppLauncherPage.tsx**
  - 页面内部重复获取用户应用列表（Home 已获取），无缓存或注入，增加网络开销。
  - 针对未登录或缺少 appId 的情形仅设置状态，未统一重定向或提示。
  - 未对 `useEffect` 中的异步请求做取消处理。

- **AnnouncementsPage.tsx**
  - 完全依赖静态 `commits.json`，缺少为空或加载失败时的占位/错误提示。
  - 提示语包含“运行脚本生成”开发向文案，用户态不可见的引导未隐藏。
  - 无分页/筛选，列表增长时可能渲染性能问题。

- **SongPicQueryPage.tsx**
  - 硬编码 API BASE（`https://api.riv62hjux.nyat.app:43419`）在前端，缺少配置化与环境隔离。
  - `navigator.clipboard` 复制无降级方案，HTTP 环境或 Safari 下可能失败。
  - `objectUrls` 仅在卸载时清理，未在新图片加载时回收，可能导致内存泄漏。
  - 大量内联样式与组件逻辑混杂，缺少拆分（列表/控制面板/预览）。

- **OngekiCardPreviewPage.tsx**
  - 运行时动态插入 CDN `html2canvas` 脚本且未清理，存在加载失败与污染全局的风险。
  - 依赖 `window.any` 与全局 DOM 查询，缺少类型与可测试性。
  - 资源路径与稀有度/属性配置硬编码在组件，缺少配置或数据层。
  - 下载功能在 CORS 失败时仅 `alert`，无错误可视化与重试机制。

- **FreedomConstPage.tsx**
  - 超大单文件组件，集成数据拉取、筛选、画布编辑、导出等多职责，维护性差。
  - 外部数据源、背景、难度配色等均硬编码且跨域，缺少缓存和失败处理。
  - 依赖 `html2canvas` 和 `contentEditable`，未处理跨域图片/文本同步的边界，易导出失败。
  - 拖拽/旋转/镜像等状态直接存储在 `useState`，缺少集中管理（如 reducer）和历史/撤销能力。

- **DownloadOrderPage.tsx**
  - 依赖浏览器内的 pako 压缩 + base64 手动处理，逻辑复杂且与后端耦合紧密。
  - `/naominet` 代理地址硬编码，缺少环境配置和错误分级。
  - 验证规则写死在前端，缺少国际化与服务端兜底校验。
  - 结果展示采用 `any` 与字符串拆分，缺少数据模型约束。

- **LicensePage.tsx**
  - 许可条款完全硬编码，存在表述矛盾（如允许“在未告知情况下的逆向”），无版本/来源引用。
  - 页面布局/背景样式重复其他页面，未抽离公共组件或布局。

- **SponsorPage.tsx**
  - 静态支付二维码路径硬编码，缺少加载失败与占位处理。
  - 布局和背景样式与其他页面重复，未复用。

- **AboutMePage.tsx**
  - 大量静态数据与图片路径硬编码在组件，缺少配置/内容管理。
  - `window.open` 直接绑定在点击事件中，未做拦截/新窗口安全属性处理。
  - 弹窗与滚动遮罩、绝对定位样式高度耦合，缺少响应式与可访问性考量。
